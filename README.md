# NEO_CLINIC — Evidencias de Análisis de Requisitos

Repositorio mantenido por **Milton Flores (`miltonfloresf606-ai`)** con la documentación de análisis de requisitos, reglas de negocio, historias de usuario, diagramas de flujo, matriz de trazabilidad y validación funcional del sistema **NEO_CLINIC**.

## Estructura del repositorio
* `01-alcance-y-actores/`: Alcance del sistema, procesos operativos y matriz de roles/permisos.
* `02-requisitos/`: Requisitos funcionales (RF), no funcionales (RNF) y reglas de negocio.
* `03-historias-y-criterios/`: Historias de usuario y criterios de aceptación (Dado / Cuando / Entonces).
* `04-flujos-y-diagramas/`: Diagramas de flujo clínico y operativo.
* `05-trazabilidad-y-validacion/`: Matriz de trazabilidad (RTM) y checklists de aceptación.
* `06-actas-y-acuerdos/`: Registro de decisiones, aclaraciones y acuerdos con el equipo.
