# Requisitos Funcionales — NEO_CLINIC

* **RF-AUT-01 (Autenticación y sesión):** El sistema debe permitir el inicio y cierre de sesión de usuarios registrados y validar el acceso según su rol.
* **RF-PAC-01 (Gestión de pacientes):** El sistema debe permitir registrar, consultar y actualizar los datos del paciente, su identificación y acompañante cuando corresponda.
* **RF-CIT-01 (Gestión de citas):** El sistema debe permitir programar, consultar, reprogramar o cancelar citas médicas, evitando conflictos de horario.
* **RF-HIS-01 (Historia clínica y alergias):** El sistema debe registrar el triaje y la consulta médica, normalizar términos de alergia y alertar ante prescripciones de riesgo.
* **RF-LAB-01 (Laboratorio clínico):** El sistema debe registrar órdenes y resultados de laboratorio, admitir formatos decimales con coma o punto y calcular rangos de referencia ajustados por edad, sexo y altitud.
* **RF-FAR-01 (Farmacia e inventario):** El sistema debe controlar el catálogo y stock (kardex), gestionar recetas, registrar ventas y mantener la consistencia de movimientos.
* **RF-FAC-01 (Facturación):** El sistema debe generar comprobantes, consultar estados de cuenta y emitir reportes de facturación vinculados a las atenciones o ventas.
* **RF-EME-01 (Emergencias y camas):** El sistema debe registrar atenciones de emergencia (incluyendo casos de identificación pendiente/NN), gestionar disponibilidad de camas y controlar hospitalizaciones.
* **RF-ADM-01 (Usuarios, respaldos y auditoría):** El sistema debe permitir administrar usuarios, ejecutar/consultar respaldos y revisar el registro de auditoría del sistema.
